ឯកសារ API

API សម្រាប់ផ្ទៀងផ្ទាត់ប្រតិបត្តិការ Bakong ដោយ MD5។ Base URL៖

https://yourdomain.com

Authentication

រាល់ request ត្រូវការ API key របស់អ្នក។ ដាក់បានតាម ៣ វិធី៖

  • JSON body — field key
  • Query string — ?key=YOUR_KEY
  • Header — X-API-Key: YOUR_KEY

កុំបង្ហាញ key ក្នុង frontend ឬ public repo។ ប្រើវាតែលើ server។

POST /api_md5

ផ្ទៀងផ្ទាត់ MD5 ដោយស្វ័យប្រវត្តិ។

POST/api_md5

Request

{
  "md5": "a1b2c3d4e5f6...",
  "key": "YOUR_API_KEY"
}

Response (found)

{
  "responseCode": 0,
  "responseMessage": "Success",
  "data": {
    "hash": "...",
    "md5": "a1b2c3d4e5f6...",
    "amount": 2.50,
    "currency": "USD",
    "fromAccountId": "user@bank",
    "toAccountId": "merchant@bank",
    "paidAt": "2025-10-14T22:45:00Z",
    "status": "SUCCESS"
  }
}

GET /api_md5/:md5

វិធី GET ងាយស្រួលសម្រាប់ test ឬ widget។

GET/api_md5/{md5}?key=YOUR_KEY

Response Format

FieldTypeការពិពណ៌នា
responseCodeint0 = ជោគជ័យ, ផ្សេង = error
responseMessagestringសារ
data.md5stringMD5 ត្រឡប់
data.amountfloatចំនួនទឹកប្រាក់
data.currencystringUSD ឬ KHR
data.paidAtstringISO 8601 timestamp

Example — cURL

curl -X POST https://yourdomain.com/api_md5 \
  -H "Content-Type: application/json" \
  -d '{"md5":"a1b2c3d4...","key":"YOUR_KEY"}'

Example — Python

import requests

r = requests.post(
    "https://yourdomain.com/api_md5",
    json={"md5": "a1b2c3d4...", "key": "YOUR_KEY"},
    timeout=15,
)
data = r.json()
if data.get("responseCode") == 0:
    print("Paid:", data["data"]["amount"], data["data"]["currency"])
else:
    print("Not found or error:", data.get("responseMessage"))

Example — Node.js

const res = await fetch("https://yourdomain.com/api_md5", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ md5: "a1b2c3d4...", key: "YOUR_KEY" }),
});
const data = await res.json();
console.log(data);

Example — PHP

$ch = curl_init("https://yourdomain.com/api_md5");
curl_setopt_array($ch, [
  CURLOPT_POST => true,
  CURLOPT_RETURNTRANSFER => true,
  CURLOPT_HTTPHEADER => ["Content-Type: application/json"],
  CURLOPT_POSTFIELDS => json_encode([
    "md5" => "a1b2c3d4...",
    "key" => "YOUR_KEY",
  ]),
]);
$res = json_decode(curl_exec($ch), true);
curl_close($ch);
print_r($res);
